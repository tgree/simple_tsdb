Up to and including the version 1.2 commit
(0b4f74f7590562c61d936fadfd2cef27548be4f9), no AI was used in the development
or testing of simple_tsdb.

Subsequent to that commit, AI will be used to expand test coverage, help in
fixing and testing bug fixes and to help expand and correct documentation.  AI
may be used to add convenience features such as better error messages or new
tsdbcli commands.  The core functionality of simple_tsdb, however, is complete
and AI is not expected to make changes to how the database actually works.
The first version number of simple_tsdb that incorporates any AI-developed
code is version 1.3.

All commits generated with the assistance of AI are marked as such with an
obvious author name such as "Claude Code", and all such commits are carefully
reviewed and receive final approval from me, Terry Greeniaus.  No AI processes
have commit privileges to the repository and no AI process is able to modify
or append to the git history without me personally pushing it in.

As always, simple_tsdb is "use at your own risk."
